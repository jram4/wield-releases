Wield for Mac

Beta 12 · version 1.0 (114)

Download Wield beta (.dmg)

Drag WieldMac.app into Applications, open it there, and follow the redesigned guided setup. Choose a few apps for a desktop demo, then explore all your commands in Studio. Replay setup from Studio → Activation → Keyboard setup, or revisit Learn Wield anytime. Send bugs and suggestions with Feedback. Basic usage analytics is enabled when no choice is stored; existing opt-outs are preserved. Manage it in Studio → Privacy. Future updates are available inside Wield.

Built for macOS 13 or later, on Apple Silicon and Intel Macs. Installation and updating have been verified on macOS 27 with Apple Silicon; older macOS versions and physical Intel Macs still need runtime testing.
