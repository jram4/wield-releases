Version 1.0 (110)

  • Setup offers Open Wield at login switched on. Open Wield Studio applies that choice. Turn the switch off before finishing if Wield should not open at login. macOS may still ask you to allow the login item.
  • Minimizing a window no longer leaves a false warning in the menu bar or Studio after the window has already minimized.
  • Signed automatic updates, the drag-to-Applications installer, six-step setup and optional clipboard recording continue.

Drag WieldMac.app into Applications and open it there. Existing settings and permissions are preserved. To reopen setup, use Studio → Activation → Run setup.

Focused checks cover onboarding and window commands. Fresh-account permission consent, physical keyboard/paste acceptance, older macOS versions and physical Intel runtime coverage remain additional beta testing.
