Wield Beta 10

Version 1.0 (112)

  • New onboarding explains tap, release and type at your pace, then lets you choose everyday apps and practice their actual commands on your desktop.
  • A small desktop guide walks through opening/switching apps, with optional Window and Calculator lessons. Skip, pause, resume or reopen Learn Wield from the menu or Studio.
  • Keep a personal reference with your actual commands. Appearance, email/calendar and File access are available through Explore Wield; existing completed users are not forced through setup again.
  • Basic usage analytics is enabled when no choice has been stored. Existing choices, including opt-outs, are preserved. Change it during keyboard setup or in Studio → Privacy. PostHog processes bounded usage/technical events in the US; typed text, clipboard contents, files, paths, screenshots and window titles are excluded.
  • File search and Clipboard recording remain explicit opt-ins. Existing command settings and signed updates continue.

Drag WieldMac.app into Applications and open it there. To revisit the guide, choose Learn Wield. This is the public Wield beta; Wield Dev remains a separate personal test app.

Focused onboarding, Calculator, Window, analytics, Studio, reliability and input/File checks have passing receipts. Physical keyboard/paste, actual tutorial window restoration, fresh-account permission flows, older macOS and physical Intel remain additional beta acceptance work.
