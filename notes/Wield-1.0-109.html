Wield Beta 7

Version 1.0 (109)

  • Six-step setup now includes explicit folder access and a Feedback introduction immediately before the final built-in guide. Unfinished setup resumes, and completed setup stays dismissed.
  • File search stays off until you choose folders. You can confirm continuing without files or enable access later in Studio → File. Older broad folder settings also wait for an explicit choice.
  • Send bugs and suggestions with the Feedback command, the menu bar or Studio’s Help & Feedback menu. Review your message, optional screenshot and optional app details before sending privately; reports are kept for 30 days.
  • Choosing Google Calendar gives it the Calendar command and distinguishes Apple Calendar. Google Chrome is displayed as Chrome; custom commands are preserved.
  • This build’s HTML release notes open as a web page. Signed automatic updates, the drag-to-Applications installer and optional clipboard recording continue.

Drag WieldMac.app into Applications and open it there. Existing settings and permissions are preserved. To reopen setup, use Studio → Activation → Run setup.

Focused checks cover onboarding, Feedback, File consent, Studio, app reopening, command suggestions and window geometry/readback. Fresh-account permission consent, physical keyboard/paste acceptance, older macOS versions and physical Intel runtime coverage remain additional beta testing.
